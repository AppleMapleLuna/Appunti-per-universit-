ORA SERVE ANCHE UN ACCOUNT GITHUB 
Esistono alternative? Sì, Bitbucket, Azure DevOps, GitLab
Github è il più conosciuto. È un archivio e piattaforma di hosting per il codice.

Qualità di github: non è presente solo l'ultima versione. C'è tutta la storia del progetto.
È anche collaborativo e si può fare e proporre modifiche.

GITHUB 
- Quando un progetto è "finito" lui inizia il suo lavoro
- Actions → Lanciato comandi sul nostro PC 
    - Abbiamo inserito un Token a mano, ora dov'è?
