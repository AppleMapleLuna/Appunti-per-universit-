Paradigma di programmazione

Quattro modi per organizzare un programma 
1. Imperativo = Sequenza di cambiamenti ← Python  
2. A oggetti = Stato + cambiamento ← Python 
3. Funzionale = Trasformazioni di valori ← Quello che vediamo oggi ← Python 
4. Logico = Fatti, regole e query ← Scriviamo il programma usando regole di deduzione. 

I paradigmi non sono compartimenti stagni: Python permette di combinarli 

Ogni paradigma ha vantaggi e svantaggi

MEMOIZATION
riusa risultati di chiamate equivalenti

from functools import lru_cache 
@lru_cache(maxsize=128) # MASSIMO 128 CHIAMATE DIVERSE
def fib(n)
    if n<2:
        return 2
    return fib(n-1+fib(n-2))
fib(30)
fib.cache_info()

AIUTA AD OTTIMIZZARE TRAMITE LRU_CACHE 
E' UNA CACHE CHE TIENE TRACIA DELLE CHIAMATE CHE ABBIAMO FATTO ALLA FUNZIONE 

Raggiunto alle 128 chiamate, cancella la memoria più vecchia

con la cache finisce SUBITO
cache si salva input e output 

Quando ha già calcolato qualcosa, non rifà i calcoli, li riutilizza dalla cache 
Se fai print non perde tempo

Problema: tutto si basa su una assunzione che la funzione è pura.
non ripete la stessa istruzione, usa quella della cache. Quindi per una variabile è diversa...
